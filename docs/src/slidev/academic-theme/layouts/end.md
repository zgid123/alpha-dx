# End Layout (`end`)

The `end` layout provides a formal concluding slide for thesis defenses, conference talks, and academic lectures.

## Presentation Preview

<LayoutDemo layout="end" theme="academic" />

---

## Usage

In your slide markdown frontmatter, set `layout: end`:

```md
---
layout: end
---

# Thank You for Your Attention
## Questions & Discussion
```

---

## Behavior

- Centers closing title and discussion prompt within academic layout styling.
- Excluded from TOC numbering where configured.
